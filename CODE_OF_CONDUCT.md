# Code of Conduct

## Our baseline

Participation in this repository must stay respectful, professional and safe for everyone.

We expect contributors to:

- bring constructive feedback tied to code, docs or product behavior;
- disagree on technical decisions without personal attacks;
- keep reviews actionable, specific and evidence-based;
- protect private data, credentials and unpublished security details.

## Unacceptable behavior

The following behaviors are not accepted in project spaces:

- harassment, intimidation or discriminatory language;
- trolling, insults or repeated bad-faith escalation;
- publishing private information without explicit permission;
- using the project spaces to pressure maintainers outside the technical scope.

## Scope

This policy applies to issues, pull requests, code reviews, discussions, chats, demos and public project communication.

## Enforcement

Maintainers may edit, hide, lock or remove content that breaks this policy.

Serious or repeated violations may lead to loss of access to collaboration spaces.

For private reports, use the contact path described in [SECURITY.md](SECURITY.md).
