# Implementation Artifacts

> Ce dossier est destiné aux rapports d'implémentation, post-mortems d'EPIC, et livrables techniques documentés après chaque sprint majeur.

## État actuel

Le code source de `grimoire-kit` vit dans [grimoire-kit/](../../grimoire-kit/) (sous-module Git).
Les artefacts d'implémentation ici documentent **ce qui a été livré** — pas le code lui-même.

## Convention

Nommer les fichiers selon le pattern : `IMPL-{EPIC-ID}-{slug}.md`

Exemple : `IMPL-EP01-core-python-package.md`

## Contenu attendu par rapport

- Epic/Story de référence
- Date de livraison
- Décisions techniques prises (divergences avec l'ADR/PRD)
- Métriques (tests, couverture, performances)
- Liens vers les commits/PRs associés
- Post-mortem si applicable
