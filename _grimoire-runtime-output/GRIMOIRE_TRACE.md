# Grimoire Runtime Trace

Journal runtime genere par les hooks `SubagentStart` et `SubagentStop`.

- Audit strict CI/preflight: `grimoire: trace-audit-strict` (alias `bmad: trace-audit-strict`)
- Reparation manuelle: `grimoire: trace-repair` (alias `bmad: trace-repair`)
- Archive legacy si migration: `GRIMOIRE_TRACE.legacy.txt`
- Sidecar machine-readable: `GRIMOIRE_TRACE.jsonl`
- Format: `YYYY-MM-DD HH:MM:SS` **Event** → `Agent`
