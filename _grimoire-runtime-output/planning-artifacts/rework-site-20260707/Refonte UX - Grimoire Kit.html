0 Synthèse · la décision en une planche
Refonte UX · Grimoire Kit · juillet 2026
Deux espaces, un socle.

Tous les problèmes constatés ont la même racine : la vitrine et l'outil vivent dans la même navigation. Le visiteur reçoit du produit qu'il ne peut pas utiliser ; l'utilisateur local retombe sur du marketing. On sépare les deux parcours — Vitrine (comprendre, public) et Atelier (opérer, local) — sans dupliquer le code : mêmes pages HTML, l'API locale active les capacités.

Les cinq décisions
Ce que je recommande — détail argumenté en §7

Chaque décision est tenable en HTML/CSS/JS vanilla, sans toucher au moteur Cytoscape ni aux données.

R1 · Renommage
Setup → Atelier

Le hub du projet courant : état, blueprints, extensions, artefacts, nouveau projet. « Setup » promettait une installation ; la page est un poste de travail.

R2 · Scission
Blueprint → Patterns + Blueprints

Le catalogue (pédagogique, public) et l'éditeur (outil, local) sont deux métiers. Même donnée catalogue-export.json, deux pages.

R3 · Repositionnement
Game UI → Labs · Game UI

Sort de la nav. Devient la pièce maîtresse d'une section « Labs » sur le Manifeste : une direction assumée, pas une feature honteuse.

R4 · Navigation
1 nav à plat → 2 navs, 1 socle

Vitrine : topbar, 5 entrées, 1 CTA. Atelier : sidebar produit avec sélecteur de projet. forge-nav.js choisit selon la détection de l'API locale.

R5 · Promesse
Ouvrir le Cockpit → Lancer l'atelier

« Cockpit » nomme une surface runtime du kit — le CTA du site doit vendre ce qui existe : le mode local. Le bouton montre la commande grimoire serve.

R6 · Onboarding
Premier flow guidé, < 2 min

4 étapes actives (ajouter ×2, connecter, simuler), départs par modèles, vocabulaire expliqué au moment où il sert. Storyboard complet en §6.

2 Trois directions · même architecture, trois peaux — mixables
2.0 · Principe
La structure est fixée, la peau se discute

L'IA de la bande 1 ne bouge plus. Les directions font varier trois choses : le modèle de nav de l'atelier, le vocabulaire, le traitement visuel. Demandé : « bousculer » — chaque direction est donc une vraie thèse, pas trois gris différents.

Direction A
La Console — un instrument, zéro décorum

Thèse : la confiance d'un dev s'achète avec de la densité maîtrisée et des états impeccables. La gouvernance n'a pas besoin de costume.

Noirs chauds, orange réservé à l'action en cours. Objets qui « pèsent » : ombres franches, gros hit targets. Motion : impacts courts (120 ms), pas de flottement.

Direction C
Le Codex — le standard comme belle ouvrage

Thèse : l'actif unique de Grimoire est son catalogue normatif. Traitons-le comme un ouvrage de référence — planches numérotées, soin typographique — et l'outil héritera de cette autorité.

7.1 · Le nom du hub
Décision : « Atelier »

Le test décisif est verbal : « je retourne à l'atelier » se dit naturellement — c'est le signe qu'un nom de lieu fonctionne. Il nomme aussi tout le mode local (« lancer l'atelier »), ce qui soude le CTA public et la page d'arrivée.
