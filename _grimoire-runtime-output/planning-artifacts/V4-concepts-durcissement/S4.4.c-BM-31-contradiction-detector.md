# S4.4.c — BM-31 Contradiction detector

## Objectif livrable

Un détecteur automatique qui scanne `_memory/decisions-log.md` et signale
les contradictions (même sujet, décisions opposées sans ADR de révision).

## Chemin de preuve

- Task `grimoire: contradiction-scan` qui produit un rapport JSON.
- Hook `grimoire-post-edit` (scope restreint à `_memory/decisions-log.md`)
  déclenche le scan et dépose un événement `scope=anomaly, phase=info` si
  contradiction détectée.
- Sortie lisible dans `_memory/contradiction-log.md` (append-only).

## Dépendances

- BM-31 (fichier log existant)
- V1 bus événements (pour l'événement `anomaly`)
- Hook gateway existant (pour brancher le scan post-edit)

## Out of scope

- LLM-based rewording detection (P3, scope V5+).
- Interface UI dédiée (l'entrée minimale est la task CLI + le ledger panel).

## Entrées attendues

- ID : `S4.4.c`
- Priorité : P1
- Owner : analyst + dev
- Préparation : auditer le format réel de `decisions-log.md` (structure des entrées, heuristique de groupement par sujet).
